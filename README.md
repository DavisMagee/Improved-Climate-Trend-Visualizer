# Improved-Climate-Data-Visualizer
Improved version of my Climate Data Visualizer. 


Now utilizes NOAA's NCEI's API so that the user no longer has to provide files to the program. 
Now only needs the Station ID, Station Name, and Date Range that the user wants to visualize. 
Station ID can be found at https://www.ncei.noaa.gov/cdo-web/search. 
AI was heavily used as I am new to API programming and JSON files. 
This was partially an exercise to better understand these parts of python.
